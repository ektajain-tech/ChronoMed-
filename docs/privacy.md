# Privacy

No account or profile is required. The app requests no creator details or medical history. Imported CSV stays in browser memory and is cleared on reload; the app does not send uploaded rows to the API or an AI service. The API has no database and does not persist session health data. Request logging does not include bodies. A delete-session control clears the client state.

The browser stores transient UI/session data only. This MVP has not undergone a formal privacy impact assessment and makes no regulatory compliance claim. Do not upload identifiable or real patient data to the demo.
